# Resenha Books

O Resenha Books é um site extremamente simples com o intuito de organizar suas leituras em três categorias: Quero Ler, Lidos, Lendo.
O livros vêm da API pública da Open Library e as listas ficam salvas no próprio LocalStorage do navegador.

Site:  https://andreluizcampos.github.io/projeto-infraestrutura-andre-campos/

## Como usar

Abra o arquivo index.html em seu navegador, contendo na mesma pasta o script.js e o style.css ou clique no link acima

## Elementos dinâmicos:
1. Menu de Hambúrguer que abre e fecha no celular;
2. Abas: Alternância de conteúdo em Lendo, Lidos e Quero Ler, sem recarregar a página
3. Busca de Livros: Formulário consulta a API e retorna um card montado.
4. Listas de Leitura: O botão "Quero ler" adiciona o elemento numa lista que pode ser remanejado entre as mesmas mediante ao que indica status ao seu lado.


## Desafios feitos:
1. Uso de API pública;
2. Dados salvos em localStorage;
3. Animações com CSS
4. Publicado no github pages
